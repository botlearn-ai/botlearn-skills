# yuan · 研究驱动的脑爆与调研

版本 1.1.0。把一个模糊的需求或想法拆成场景、角色和问题，去查市面上的同类产品和 GitHub 开源实现，发散出几条走法再收敛成一个推荐，最后交一份每条事实都带来源的脑爆文档。

适合：做产品或方案之前的前期调研、竞品摸底、梳理需求、行业机会分析。
不适合：优化提示词或 skill（用同包里的 yuanskill-pro），直接写代码。

| `CHANGELOG.md` | 版本记录，以及每条机制从哪里借来的 |

## 安装（Claude Code）

所有项目都能用：

```bash
cp -R yuan ~/.claude/skills/yuan
```

只给某个项目用：

```bash
mkdir -p 你的项目/.claude/skills
cp -R yuan 你的项目/.claude/skills/yuan
```

装完新开一个会话生效。文件夹名必须是 `yuan`，和 `SKILL.md` 里的 `name` 一致；顶部的 YAML 头不要删，`references/` 和 `assets/` 的目录名、文件名也不要改。

## 怎么用

直接说需求就会触发，比如「帮我脑爆一下」「梳理场景和需求」「市面上有没有类似的」「GitHub 有没有同类代码」「做个调研」。也可以点名：`/yuan` 或「调用 yuan」。

它会先判断模式并告诉你，你可以否决：

- BASIC 快脑爆：问题小、只要思路。不怎么联网，直接在对话里给出需求解构、前提、三条走法和推荐。
- DETAIL 全流程：要做系统、产品或方案，或者要查竞品和开源代码。动手前最多问 2–3 个问题，每个都带推荐默认值，最后交一份完整文档（默认是图文 HTML）。

用的时候你会注意到几件事：

1. 它会先质疑题目本身，把「前提」写出来让你认。
2. 至少给三条走法：最小可行、理想形态、横向一招，最后落到一个能说好或不好的推荐上。
3. 推荐定了以后，会请四个视角挑刺（一线使用者、出钱的人、反方投资人、领域专家），意见要么改推荐，要么进风险表。
4. 每条事实标来源，只有一个来源的标「单源」，超过两年的数据标「旧数据」，事实、推断、建议分开写。

需要浏览器登录的平台（小红书、抖音这类），它会停下来请你自己登录，不会代填账号密码，也不会代过验证码。

## 其它平台

全部是纯 Markdown，不依赖脚本。平台不支持 skill 的话，把 `SKILL.md` 当系统提示词，`references/` 当知识库喂进去也能用。

## 和 yuanskill-pro 的关系

yuan 是从 yuanskill-pro 分出来的。两个可以同时装，触发词不重叠：要调研和脑爆用 yuan，要打磨一段提示词或一个 skill 用 yuanskill-pro。
